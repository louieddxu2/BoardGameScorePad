# 歷史紀錄日期篩選計畫

日期：2026-11-02

狀態：已實作。

## 目標與範圍

讓使用者明確指定遊玩日期、月份、年份或範圍，歷史清單、統計與照片回顧共用同一個日期條件。

- 日期依紀錄上顯示的遊玩日期判定，來源沿用 `endTime` 與使用者當地日曆。
- 日期條件直接比對時間區間，不經過模糊搜尋。
- 移除原本近30天／近3月／近1年的輪流切換，改為全期間、這個月與自選。
- 原本日期文字欄位退出歷史紀錄的模糊搜尋；指定日期改由時間篩選入口承接。
- 遊戲名稱、玩家、地點的文字比對維持現況；人名身分選取、備註搜尋及整體文字搜尋政策另行討論。
- 不從搜尋文字猜測日期，不新增日期語法、自動轉換或搜尋建議。

## 第一層：上拉式選單

沿用統計面板現有時間按鈕，點按後開啟既有樣式的上拉選單，順序固定為：

1. 自選…
2. 這個月
3. 全期間

- 全期間、這個月：立即套用並收起選單。
- 自選：先收起選單，再開啟日期設定彈窗；此時不改變已生效條件。
- 勾選目前使用的選項。自選與這個月即使暫時涵蓋同一區間，也保留使用者實際選擇的種類。
- 按鈕顯示目前條件：全期間、這個月，或自選的具體日期／年月／年份／範圍。長範圍可簡寫，完整內容須能在選單或彈窗確認。

## 第二層：漸進式日期設定

### 日期語意與精度控制

- 彈窗標題使用「自選遊玩日期」。
- 保留動態列表原日期篩選器的年／月／日累進選取；以明確可點按的按鈕呈現，不把一般單位標籤當成隱藏開關。
- 選年：只啟用年。選月：啟用年與月。選日：啟用年月日。
- 已包含的層級依序亮起；未使用的欄位位置保留，停用並顯示「－」。
- 精度控制只保留一處，同時作用於所有已展開的日期列。
- 年／月／日精度按鈕同時作為欄名，與所有日期滾輪使用相同的三欄等寬排版及欄距；不另加「選到」、滾輪單位標籤或單一輸入標題。
- 範圍模式只顯示「開始／結束」，無障礙名稱仍依精度提供完整的開始日期／月份／年份與結束日期／月份／年份。
- 移除先前示意中的「查看某一天」選單，避免再引入一套與年月日精度重複的控制。

### 初始只顯示一組輸入

- 預設為單一時間，一組滾輪即可選一天、一個月或一年。
- 年份支援直接輸入；年月日可滑動調整，改年月時將日期限制在該月有效天數內。
- 不常駐顯示單一／範圍切換列、第二組滾輪、重複日期摘要或操作說明段落。
- 全期間、這個月已由第一層承接，不重複放進自選彈窗。

### 需要時展開範圍

- 單一輸入下方提供「＋設定範圍」。
- 點選後，第一組明確改標為開始，並展開結束輸入；初值複製目前選擇，使用者再調整結束。
- 展開後兩組數值獨立編輯，不增加結束值自動跟隨開始的隱性規則。
- 結束列提供收回範圍的控制。回到單一時優先保留開始值；若開始不限，則取結束值。
- 只在展開範圍後提供每一端的「不限」。不限欄位顯示「－」，滑動可恢復設定，沿用參考專案的操作。
- 結束早於開始時，在該處顯示錯誤並停用套用；起訖相同合法。

### 套用、取消與重新開啟

- 彈窗使用獨立草稿；只有按套用才更新清單與統計，套用後關閉。
- 關閉、返回、取消都丟棄未套用修改，維持原條件。
- 從全期間進入：預填今天、日精度、單一輸入，不先產生任何篩選。
- 從這個月進入：預填目前月份、月精度、單一輸入。
- 從自選進入：還原已套用的精度、單一／範圍、起訖與不限狀態。
- 範圍由年改選月時，保留完整起訖年度的月份邊界；由月改選日時，保留完整起訖月份的日期邊界。
- 單一輸入改精度時保留共同的年、月與有效日期值；顯示新草稿供確認，不擅自展開成範圍。
- 雙端不限套用後等同全期間。

## 日期規則

| 選法 | 實際涵蓋範圍 |
| --- | --- |
| 單日 | 指定當地日曆日的全部時間 |
| 單月 | 指定年月第一日至最後一日 |
| 單年 | 指定年份1月1日至12月31日 |
| 日期範圍 | 開始當天至結束當天，包含兩端 |
| 月份範圍 | 開始月份第一日至結束月份最後一日 |
| 年份範圍 | 開始年份1月1日至結束年份12月31日 |
| 單端不限 | 從開始起，或截至結束，包含有指定的端點 |
| 這個月 | 依目前當地日曆解析的整個月份，不是最近30天 |

- 年份支援1至9999，檢查有效年月日、閏年及跨年。
- 使用當地日曆邊界，內部以起日零時至迄日次日零時前表示；不可用UTC日期字串或固定24小時推算，避免時區與夏令時間錯日。
- 這個月保留為動態條件；自選某年某月為固定條件。進入歷史頁、重新操作篩選或回到前景時確認目前月份，不新增常駐輪詢。
- 有日期條件時，無效日期紀錄不符合；不填補日期、不修寫歷史資料。

## 資料範圍與狀態

1. 將目前統計面板內部的日期狀態移到歷史查詢的共同資料層，只保留一份已套用條件。
2. 沿用原有歷史讀取與待刪除遮罩，再套用日期條件與文字搜尋。
3. 由同一批完整結果提供歷史數量、歷史清單、遊戲彙整與統計；清單最後才套用既有顯示上限。
4. 統計面板移除重複的30／90／365天過濾。原有地點、規則、人數與遊戲／玩家詳情範圍維持各自現有職責。
5. 日期條件只作用於歷史資料，不影響首頁遊戲候選、模板搜尋、玩家偏好或資料儲存。
6. 開啟歷史詳情再返回時保留條件；切換頁面與重新打開時間設定時也保留已套用狀態。本次不新增跨重新載入的儲存格式。
   關閉統計後，歷史清單上方保留生效中的日期條件及清除入口，避免篩選狀態隱藏。
7. 照片回顧沿用已實作的開窗快照，包含所有最終符合紀錄與無照片紀錄；編輯途中不更新範圍。
8. 圖片標頭仍顯示紀錄實際涵蓋的固定日期，不印這個月、自選或未涵蓋紀錄的篩選邊界。

## 實作切分

- `historyDateFilter.ts`：條件型別、日期驗證、區間解析、標籤與精確比對等純函式。
- `HistoryDateFilterControl.tsx`：現有時間按鈕、上拉選單、自選彈窗開關與草稿交接。
- `HistoryDateFilterModal.tsx`、必要的滾輪元件：精度控制、單一／範圍漸進揭露、輸入與驗證。
- `useHistoryQuery.ts`：共同日期狀態、日期及文字過濾、結果數量；更新必要的上層傳遞介面。
- `HistoryStatsPanel.tsx`：改接共同日期條件，移除舊循環選項與重複過濾；不在此檔持續擴充整個編輯器。
- `history_stats.ts` 與相關字典：補齊zh-TW、en文案及無障礙標籤。
- 參考動態列表的操作與日期規則，在本專案使用既有主題及彈窗返回管理，不跨專案匯入或修改對方元件。
- 每個產品原始碼檔案不超過600行，維持既有讀取、手勢與清理責任，不增加重複查詢。

## 驗證與完成條件

- 純函式：單日／月／年、同值與跨單位範圍、月底、閏年、跨年、時區邊界、單端不限、無效日期、本月跨月解析。
- 介面：自選置頂；預設項即時套用；只有自選開彈窗；首次只顯示一組輸入；精度按鈕與「－」對應；範圍展開／收回；年份直接輸入；滾輪滑動與點選不重複觸發；錯誤、取消與重新開啟。
- 查詢整合：日期加文字為交集；日期不再模糊命中；數量與清單上限；刪除遮罩；清單與統計共用日期結果；既有其他搜尋欄位不受影響。
- 回顧回歸：同一天不同時間、無照片紀錄、多年範圍、單一遊戲多場照片、圖片實際日期及開窗快照。
- 實作時先跑相關測試、`npx tsc --noEmit`、中文字串掃描及正式建置；按範圍執行核心回歸，不重複執行無變更的相同檢查。
- 未明確要求前不開瀏覽器；手機原生手勢與視覺驗收若尚未執行，需清楚回報限制。
- 實作完成後本機提交；只有另行明確要求發布時才執行V3test發布流程。發布記錄於合併main前整理。

實作保留動態列表的日期精度與滾輪操作，並使用本專案的主題、查詢及彈窗管理。
