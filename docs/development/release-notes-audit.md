## 查證方式

- 以 main 的合併紀錄及 reflog 中的 fast-forward 時點分版，使用 `git merge-base --is-ancestor` 確認功能首次落在哪次正式合併；不以功能提交日期代替發布日期。
- 比較各版程式、資料與測試。提交標題供定位，分類仍依使用者新增了什麼能力、既有行為如何改變或哪個錯誤被修正判斷。
- 早期功能另核對 `docs/萬用桌遊計分板網頁App介紹.docx`。該文明載 V2 於 2025-12-21 發布且有 23 款內建計分板，以及 V3.5 於 2026-02-21 發布。
- 同時比對 `src/data/templates.ts` 與 `templates-en.ts`，不將中文限定的計分板變更翻譯成英文版功能。
- 保留可驗證的行為，刪去無依據的準確率比較、完整性保證與泛稱內部整理。中英文分別檢查意思、範圍與長度。
